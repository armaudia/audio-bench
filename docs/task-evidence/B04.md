# B04 — Native SDK driver and trusted collector

**Status: implemented for local integration with the pinned installed SDK; not an untrusted
submission runner and not independently security-reviewed.**

## Implementation

- `native/CMakeLists.txt` constrains `find_package` to the verified prefix and checks the selected
  config file and imported header/library paths. Configure verifies all 38 Candidate 09
  installed-prefix files, the exact archive hash and copied manifest before consuming the package.
- `native/src/driver.cpp` runs the SDK session sequentially, carries state across a recording,
  accepts a final partial frame, explicitly drains, resets between recordings and closes only
  after DRAINED.
- `native/src/collect.cpp` is a separate supervisor. It owns request sequence numbers, launches a
  process group, uses bounded nonblocking pipes with poll timeouts, reads prevalidated float input,
  retains raw output/source maps, checks interval continuity, and records collector receive clocks,
  elapsed time, direct child CPU and collector CPU/RSS. It runs only the named built-in SDK fixtures
  in the demonstrated smoke; arbitrary submissions are not enabled.
- `native/src/wire.cpp` and `src/audio_bench/ipc.py` implement protocol v1. Native reads/writes use
  one absolute timeout per complete IPC message; driver shutdown and the whole child run are
  bounded, and cleanup attempts kill the process group. This is local lifecycle behavior, not
  verified containment against hostile descendants.
- `native/src/wire.cpp` and `src/audio_bench/ipc.py` implement protocol v1. INPUT and SDK OUTPUT
  flags are distinct. Drain audio is OUTPUT/phase DRAIN; DRAINED is an acknowledgement. RESET and
  CLOSE are explicit. Golden vectors cover every message type.
- `native/tests/d256_regression.cpp` source-links a multi-drain identity-delay fixture through the
  installed SDK facade. It checks every frame's source interval, sample content, validity and flags,
  bounded drain, nonzero origins, both SDK modes, and every final remainder 1–159. The loaded config
  schema bytes are hashed and matched to the descriptor. Candidate 09 passes. The exact historical
  `82bb8f64…` archive fails on its first frame: `(valid_offset,valid_count)=(160,96)`, expected
  `(160,0)`.
- A native integration test also feeds a recording ending in a partial frame followed by another
  recording; the collector reports complete coverage for both, with accepted counts 161 and 320.

## Remaining

verification, cancellation fault suite, or independent collector/security review exists. The
implementation is restricted to the reviewed installed SDK and synthetic fixture path.
