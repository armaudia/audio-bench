# B08 — Isolation and safe export

**Status: offline candidate sanitizer implemented and synthetic adversarial checks pass; untrusted
execution and public publication remain gated.**

`build_offline_candidate()` is callable without enabling `export_candidate()`. It uses explicit
field-path projections with closed typed public schemas, public schema IDs, rejects private text
canaries, bounds canonical JSON/JSONL and checks WAV channel/rate/frame/decoded-byte bounds before
allocation/decode, requires per-media redistribution and public-playback decisions with evidence
references, uses descriptor-relative no-follow reads, and builds a new public inventory/core from
projected bytes. `approve_export()` binds the exact candidate inventory and checks the supplied
public-core digest. `build_public_report()` verifies that exact approval, the core/inventory/payload
identities, public record schemas, and config/provider/cohort references before writing a static
offline report.

```text
.venv/bin/python -m pytest tests/unit/test_acquire_export.py \
  tests/unit/test_export_security.py -q
  PASS (included in final full suite): symlink/path/canonical/depth checks, record-type canaries,
  rebuilt public hashes, required media rights, prebounded WAV decode, failure atomicity, exact
  approval → sanitized public core → static public report flow
```

Remaining: `export_candidate()` intentionally remains gated; no disposable isolation host, separate
publisher identity, independent security review, browser/gallery acceptance, or authorized public
media exists. Public report/config/provider bindings are local validation only; passing tests are
not containment evidence or approval authority.
