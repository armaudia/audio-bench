# B08 — Isolation and safe export

**Status: offline candidate sanitizer implemented and synthetic adversarial checks pass; untrusted
execution and public publication remain gated.**

`build_offline_candidate()` is callable without enabling `export_candidate()`. It uses explicit
field-path projections per record type (no schema-wide property-name union), rejects private text
canaries, bounds canonical JSON/JSONL and full WAV decode, requires per-media redistribution and
public-playback decisions with evidence references, uses descriptor-relative no-follow reads, and
builds a new public inventory/core from projected bytes. New output is staged in a temporary sibling
and atomically renamed only after success. `approve_export()` binds the exact candidate inventory
and checks the supplied public-core digest.

```text
.venv/bin/python -m pytest tests/unit/test_acquire_export.py \
  tests/unit/test_export_security.py -q
  PASS (included in final full suite): symlink/path/canonical/depth checks, record-type canaries,
  rebuilt public hashes, required media rights, WAV decode, failure atomicity
```

Remaining: `export_candidate()` intentionally remains gated; no disposable isolation host, separate
publisher identity, independent security review, full public descriptor/config approval binding, or
authorized non-synthetic public media exists. Passing local tests is not containment evidence.
