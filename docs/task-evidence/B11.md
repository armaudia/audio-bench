# B11 — Durable automation and publication

**Status: local groundwork implemented; external automation/publication is not started and remains
blocked.**

`src/audio_bench/reconcile.py` provides:

- conservative local impact tiers with manual review required;
- a file-locked local reconciliation event log;
- idempotent replay for an identical `(source, scope, sequence, request, core)` tuple;
- no advancement for incomplete or out-of-order evidence; and
- rejection of conflicting evidence at an already-used sequence.

The event/latest-snapshot records have closed schemas. `tests/unit/test_reconcile.py` checks
incomplete attempts, idempotency, advancement, out-of-order protection and conflicting sequence
rejection. These checks establish behavior for this local file implementation only, not durable
storage under machine loss, distributed concurrency or a remote append-only service.

```text
.venv/bin/python -m pytest tests/unit/test_reconcile.py -q
  PASS: 2 tests (also included in the final 72-test suite)
```

No workflow, webhook/request service, remote ledger, target runner, dedicated machine lock,
publisher credentials, remote repository, deployment or external publication was created. B11
cannot be accepted until the manual B01–B09 path and B08 security gates are reviewed and the
external infrastructure/retention/approval requirements are specified. This is not a continuous
benchmark or publishing automation.
