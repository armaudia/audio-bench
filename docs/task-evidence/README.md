# Archived task evidence

Files in this directory record intermediate implementation reviews, tests, and
decisions as they were known when each task was completed. Some statements about
dataset scoring, operating systems, submission status, and rights were later
superseded. They are retained as historical evidence and should not be used as
current product or release claims.

For current behavior and policy, use:

- [`README.md`](../../README.md) for repository status and supported workflows;
- [`SUBMISSIONS.md`](../SUBMISSIONS.md) for benchmark intake and result handling;
- [`CORPUS.md`](../CORPUS.md) and [`DATA_LICENSE.md`](../../DATA_LICENSE.md) for
  dataset acquisition, rights, caching, and scoring scope;
- [`RELEASING.md`](../../RELEASING.md) for target support and release gates; and
- [`qualification/status.json`](../../qualification/status.json) for the current
  workload qualification decision.

Removing a result from the live report does not alter archived task evidence,
Git history, or old Actions artifacts.
