# B02 — Schemas, JCS identities and immutable ledger

**Status: implemented and locally tested for the current schemas and sealed synthetic attempts.**
Independent review and production signing remain outstanding.

## Implemented

- Draft 2020-12 control schemas are closed, indexed and validated offline. `schemas/index.json`
  covers project schemas and the exact installed-SDK schema copies. SDK schemas/descriptors are
  available under `schemas/sdk/`; descriptor validation verifies the pinned schema digest before
  use.
- `canonical.py` uses pinned `rfc8785==0.1.4`, rejects duplicate keys, BOM, malformed UTF-8,
  nonfinite values and lone surrogates, and verifies omitted-self-field content IDs.
- The request matrix may freeze exact expected payload paths. Sealing recomputes actual inventory,
  file hashes and the content-addressed core; the run manifest permanently keeps `core_digest=null`.
- New reconciliation/impact-plan/latest-snapshot schemas support the local B11 ledger groundwork.
- Schema and report resources are packaged in the wheel; source-tree and packaged schemas are
  byte-compared by tests.
