# audio-bench repository handoff

Planned public repository. This directory currently contains implementation instructions, not an implemented harness or deployed report.

Read [the shared handoff](../plan/implementation_handoff_20261113.md), then [implementation steps](IMPLEMENTATION_PLAN.md), [evidence specification](EVIDENCE_SPEC.md) and [test plan](TEST_PLAN.md). This repository owns evaluation methodology, asset/catalog records, immutable evidence, measured runtime and public reports.

It consumes a pinned installed audio-sdk package and its conformance tools. Private providers are optional inputs; public correctness and report builds require no private credentials. It never redefines SDK runtime contracts.
