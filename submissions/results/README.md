# Submitter-owned result records

This directory currently contains no result records. Add a reviewed JSON result
here only after running the pinned submitter workflow in the private repository
or on owner-controlled infrastructure. Do not add source code, model weights,
audio, repository URLs, credentials, or private data. The intake workflow
validates result metadata only and never checks out or executes the private
project. See [the result protocol](../../docs/SUBMISSIONS.md#submitter-owned-runner-for-private-source).
