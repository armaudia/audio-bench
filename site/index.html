Understand the results

Start with the suite, then check who ran it and on which machine.

Speech enhancement

VoiceBank+DEMAND uses 824 paired clips with clean references. Higher SI-SDR improvement means fewer distortions relative to the noisy input. Higher STOI and ESTOI indicate better predicted intelligibility.

Speech scoring protocol ↗

Real-time processing

The paced suite tests up to 16 concurrent worker processes with synthetic audio. More streams meeting the 10 ms deadline indicates higher tested capacity. Lower p99 lateness means frames finish closer to schedule.

Real-time test profile ↗

Run evidence

Audio Bench runs use the project’s CI runner. Submitter runs come from the submitter’s environment and are not independently verified. Synthetic smoke runs check integration. Use matching suites and comparable hardware when comparing runtime.
